# Morrowind Remastered

Morrowind Remastered is a purist-friendly modlist for The Elder Scrolls III: Morrowind, it aims to modernise the game with enhanced graphics, quality of life improvements, and updated convenience features that don't interfere with the core gameplay and mechanics of the original. 

The list contains two distinct versions, each with similar, but distinctly different modlists. They are installed together, and you can play either or both from the same installation.

## OpenMW Edition

The **OpenMW** edition runs Morrowind using the OpenMW engine, allowing for improved stability and graphics enhancements. 

This version features the better graphical improvements and immersion features than the MWSE edition, but lacks some of the quality of life and UI improvements. 

## MWSE Edition

The **MWSE** edition runs Morrowind using the original game engine, with Morrowind Code Patch, MGE XE, and MWSE to provide improved graphics and a rich selection of quality of life improvements.

This version features more quality of life additions and a much improved user interface, but lacks the same degree of graphical improvements as the OpenMW edition, and may be more prone to crashes.

# Installation Instructions

There are two ways to install this modlist, you can either do so directly through Wabbajack, or by using the Morrowind Remastered launcher (which installs and runs Wabbajack for you). The Morrowind Remastered launcher requires NexusMods premium to use it for installation.

_Please note, if you are installing the legacy edition of Morrowind Remastered, only the Wabbajack method is available._

## Option 1: Morrowind Remastered Launcher
- Install Morrowind through either Steam or GOG. 
    - _If you already have Morrowind installed, and you have modified the game files at any point, please reinstall a fresh copy of Morrowind._
- Download the Morrowind Remastered Launcher: []()
- Move `MorrowindRemastered.exe` to wherever you wish to install the modlist.
- Run `MorrowindRemastered.exe` as an administrator.
- Select the location of your unmodified Morrowind installation. You can optionally take a copy of the unmodified game for the modlist to use, but it is not required.
- Click to sign in to your NexusMods premium account, you cannot use the launcher to install the list without one.
- Click `Install` and wait for the game to install. This can take a long time.
- Select `OpenMW` (for OpenMW Edition) or `MWSE` (for the MWSE Edition) in the left side of the launcher, and click Play to play the game, all post-installation setup will run automatically the first time you play the game.

## Option 2: Wabbajack
- Install Morrowind through either Steam or GOG. 
    - _If you already have Morrowind installed, and you have modified the game files at any point, please reinstall a fresh copy of Morrowind._
- Download Wabbajack: [Wabbajack.org](https://www.wabbajack.org/)
- Run `Wabbajack.exe`
- Go to Settings, and sign in to your NexusMods account.
    - _I STRONGLY suggest Nexus Premium for this process, it is not expensive, and you only need it while installing, so you will only need to purchase a single month. If you do not have Premium, you will be prompted to manually download each file yourself, and this can be very time consuming._
- Click `Browse lists` on the left hand side of Wabbajack.
- Check the box labelled `Non-featured` to show all lists.
- In the `All games` dropdown, select `Morrowind`.
- Find Morrowind Remastered and select the version you want;
    - Morrowind Remastered, the main modlist, containing both OpenMW and MWSE versions.
        - OpenMW Edition, the latest release, enhanced graphics, quality of life, and immersion improvements. The best for graphics.
        - MWSE Edition, the latest release, enhanced graphics, quality of life, and immersion improvements. The best for quality of life mods.
    - Morrowind Remastered - Legacy Edition, the original version, exceptionally purist, but somewhat outdated.
- Click `Download & Install`.
- Select the location to install the modlist, but do NOT select a location inside the Morrowind install folder.
- Optionally, select a separate download location (only do this if you intend on installing multiple lists and want to minimise download times).
- Click `Install`, and allow Wabbajack to download and install the modlist. This may take some time.
    - _If the installation fails, Wabbajack should list the specific downloaded files that failed. Go to the download location you specified and delete those files only, then re-attempt the installation through Wabbajack. This will save you from having to re-download everything._
- Once the installation is complete, click `Open Install Folder`.
- Run `MorrowindRemastered.exe` as an administrator and select the location of your unmodified Morrowind installation. You can optionally take a copy of the unmodified game for the modlist to use, but it is not required.
    - _For the Legacy edition, run `ModSetup.exe` and follow the setup steps as directed. When complete, launch `ModOrganizer.exe` and click run to play the game._
- Select `OpenMW` (for OpenMW Edition) or `MWSE` (for the MWSE Edition) in the left side of the launcher, and click Play to play the game, all post-installation setup will run automatically the first time you play the game.
